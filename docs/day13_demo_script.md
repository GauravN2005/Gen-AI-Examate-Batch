# Day 13 Demo Script

## 2-3 minute recording script

1. **Introduction (20 seconds):** Introduce FundFacts and SchemeSaathi as a
   beginner-friendly mutual-fund education assistant grounded in SEBI sources.
2. **Problem (20 seconds):** Explain that beginners need clear explanations of
   SIP, NAV, Riskometer, costs, and risks without personalised advice.
3. **Streamlit chat (25 seconds):** Ask "What is NAV?" and show the generated
   answer, expanded citations, and disclaimer.
4. **Safety guard (20 seconds):** Ask "Which mutual fund should I buy?" and
   show the fixed Education, not advice refusal card and SEBI resources.
5. **SIP agent (25 seconds):** Submit a NAV-based SIP calculation and show the
   pending approval state.
6. **Approval (15 seconds):** Approve the request and explain that it executes
   only illustrative deterministic arithmetic after approval.
7. **Production features (20 seconds):** Mention structured latency logs,
   provider usage fields, bounded TTL caching, input limits, and the
   prompt-injection test.
8. **Deployment (15 seconds):** Show `/health` locally or the public URL only
   after it has been verified. Do not claim deployment until Render confirms it.
