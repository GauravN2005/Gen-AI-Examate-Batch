# Day 12 Pull Request Guide

Create and merge a pull request manually after CI passes.

1. Create a feature branch locally.
2. Commit all reviewed Day 12 changes to that branch.
3. Push the branch to GitHub.
4. Open a pull request from the feature branch to `main`.
5. Wait for Ruff, pytest, and Docker checks to complete.
6. Open the successful Actions run and the PR checks page.
7. Fix failing checks before merging.
8. Merge only after all required checks are green.
9. Verify that the workflow runs successfully on `main`.
