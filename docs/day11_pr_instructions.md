# Day 11 Pull Request Instructions

This process must be performed manually; do not infer or invent PR evidence.

1. Create a feature branch for the Day 11 changes.
2. Review `git status` and commit the files to that branch.
3. Push the feature branch to GitHub.
4. Open a pull request targeting `main`.
5. Wait for the `CI / ruff`, `CI / pytest`, and `CI / docker` checks to finish.
6. Capture the pull request URL and a screenshot of the successful checks.
7. Merge the pull request only when every required check is green.
8. Verify that the workflow runs successfully on `main`.
