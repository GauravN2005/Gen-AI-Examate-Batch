# Beginner FundFacts User Questions

These questions are checked against the current 20-record
`data/sample_records.json` dataset.

## 1. SIP

**User question:** What is a SIP, and how does investing a fixed amount every
month work?

**Related concept:** Systematic Investment Plan  
**Can the current dataset answer it?** Yes.  
**Reason:** The dataset explains fixed, regular investments and includes a
simple monthly-investment example.

## 2. NAV

**User question:** What does NAV mean, and does a lower NAV mean that a fund is
cheaper?

**Related concept:** NAV / Net Asset Value  
**Can the current dataset answer it?** Yes.  
**Reason:** The dataset defines NAV and warns that NAV alone does not indicate
investment quality.

## 3. Direct vs Regular Plan

**User question:** What is the difference between a direct plan and a regular
plan?

**Related concept:** Direct Plans and Regular Plans  
**Can the current dataset answer it?** Yes.  
**Reason:** The records describe distributor involvement, expenses, examples,
and related risks.

## 4. Riskometer

**User question:** What does the Riskometer tell me about a mutual fund
scheme?

**Related concept:** Riskometer  
**Can the current dataset answer it?** Yes.  
**Reason:** The dataset describes the Riskometer as a visual risk-level tool
and lists its six levels.

## 5. KYC

**User question:** What is KYC, and why do I need to complete it before
investing?

**Related concept:** KYC  
**Can the current dataset answer it?** Yes.  
**Reason:** The dataset explains KYC as identity and address verification and
includes a warning about protecting sensitive credentials.

## 6. Guaranteed Future Return

**User question:** Which mutual fund will give me the highest guaranteed return
next month?

**Related concept:** Future investment prediction  
**Can the current dataset answer it?** **Not answerable from the current FundFacts dataset.**

**Reason:** The dataset contains educational information, not future
predictions. No mutual fund can be presented as guaranteeing the highest future
return, and FundFacts must not recommend specific funds.

## 7. Investment Scams

**User question:** What warning signs should I look for if someone promises me a
guaranteed mutual fund return?

**Related concept:** Investment scams  
**Can the current dataset answer it?** Partially.  
**Reason:** The current sample dataset warns against guaranteed returns, but it
does not contain a dedicated scam-awareness record with a complete checklist.

## 8. Expense Ratio

**User question:** What is an expense ratio, and how can it affect my
investment?

**Related concept:** Expense Ratio / Total Expense Ratio  
**Can the current dataset answer it?** Yes.  
**Reason:** The records explain the annual charge, provide an example, and
warn that expenses reduce investor returns.

## 9. STP and SWP

**User question:** What is the difference between an STP and an SWP?

**Related concept:** Systematic Transfer Plan and Systematic Withdrawal Plan  
**Can the current dataset answer it?** Yes.  
**Reason:** The dataset explains transfers between schemes and periodic
withdrawals as separate facilities.

## 10. Exit Load and Nomination

**User question:** What is an exit load, and what is nomination used for in a
mutual fund account?

**Related concept:** Exit Load and Nomination  
**Can the current dataset answer it?** Yes.  
**Reason:** Separate records explain the possible redemption charge and the
purpose and limitation of nomination.
